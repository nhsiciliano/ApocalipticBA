# Referencias visuales — Escenario 1 "Constitución"

Carpeta de uso **interno exclusivamente**. Las imágenes las coloca el usuario y están excluidas del repositorio por `.gitignore` (solo este README se versiona).

Archivos esperados (cualquier extensión de imagen):

- `01-estacion-exterior` — fachada de la estación: piedra salmón, cúpula central con reloj, mansardas.
- `02-estacion-hall` — hall: bóveda de cañón casetonada, luneta, galería superior, piso de rombos terracota/gris.
- `03-plaza` — plaza: lajas grises, canteros, palos borrachos, columnas de alumbrado.
- `04-iglesia` — iglesia neogótica: dos torres de alturas distintas, rosetón, portales ojivales, reja de hierro.

Reglas:

- No se publican ni se incluyen en builds, landing ni press kit.
- No se usan como input (`--image`) de generación de assets en Genex ni en ninguna otra herramienta.
- Sirven solo para que el equipo contraste proporciones y paleta al construir el blockout y las piezas modulares.
